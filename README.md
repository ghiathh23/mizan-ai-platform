# MIZAN AI

Arabic-first, multi-tenant water services management, governance, data intelligence, and decision-support platform.

## Engineering status

- Phase: 0 — Environment Discovery / Phase 1 — Architecture
- Status: Architecture baseline in progress
- Production readiness: Not assessed

## Principles

- Tenant isolation is enforced server-side and at the database layer.
- Transactional data is the source of truth.
- AI and OCR outputs are proposals or analytical context, not authoritative transactions.
- Arabic and RTL are first-class product requirements.
- Field workflows must support offline operation.
- Implemented, Tested, Verified, and Production Ready are reported separately.
